# Examples

Example `.takt` files used for development, tests and demos.

Rules:

- **Chords and structure only.** Do not commit lyrics of copyrighted songs. Use your own text, public-domain songs, or leave lyrics out.
- One song per file, named in lowercase latin with hyphens: `dostoinyi-ty-odyn.takt`.
- Keep real-world quirks (empty bars, `A - E`, `(2x)`) — they are test cases for the parser.
